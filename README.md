# 준공! (가제)

현장소장이 되어 작업팀 카드를 내고, 망치질로 벽돌을 쌓아 건물을 끝까지 올리는 도트 그래픽 1:1 카드 배틀 웹 게임입니다.
한 판은 5분 안에 끝나고, 철근 → 거푸집 → 타설 순서, 양생, 방호 같은 시공 개념을 놀이로 익힙니다.

## 실행

설치가 필요 없습니다. `index.html`을 더블클릭하면 브라우저에서 열립니다 (Chrome, Edge 확인).
휴대폰은 가로로 눕혀서 하는 걸 기준으로 합니다.

## 담긴 것

- 현장 5곳 (단독주택 → 근린생활시설 → 장마철 아파트 → 겨울 물류센터 → 도심 지하 굴착)
- 카드 32장 (기본 7 + 현장 첫 준공 보상 10 + 모은 별로 여는 15), 현장 문제 7종, 현장 조건 3종 (집중호우, 한파, 연약지반)
  - 별로 여는 카드는 건축 실무·전공 11장(조적공, 방수공, 철골공, 용접공, 레미콘 기사, 비계공, 감리원, 공정표 작성, 압축강도 시험, 기성 청구, 안전점검)과
    게임 요소 4장(견습공, 굴착기, 베테랑 반장, 다능공). 여는 순서와 별 수는 `data/cards.js`의 `JG.CARD_UNLOCKS`에서 바꿀 수 있습니다
- 아침 TBM 다짐, 준공 결과 (기념사진 PNG 저장, 실제 기록으로 그린 공정표, 칭호, 새 카드)
- 우리 회사 단지, 도감 (용어 풀이·현장 말), 자재 창고 (덱 편집), 난이도 3단계, 효과음·배경음
- 데일리 현장 (날짜로 정해져 누구나 같은 현장), 수업용 현장 (6자리 시나리오 코드)
- 수업용 해설 (시공·재료·구조·안전 단원별 정리), 용어 OX 3문제
- 대전 연출: 카드가 대상에게 돌진·피격, 떠오르는 피해 숫자, 화면 흔들림, 턴 알림판 (동작 줄이기 설정이면 숫자만)
- 문제 행동 미리 보기 (다음 현장 턴에 누구를 칠지, 치면 해결되는지), 자재 검수·남은 자재 보기·자재 소진
- 공정 순서: 철근 → 형틀 → 타설 작업팀을 차례로 내면 공정 완료 (벽돌 +2)
- 전장식 요소: 키워드(안전모·퇴장 효과·연속 망치질·등장 효과), 숙련 승급(같은 작업팀을 겹쳐 내면 금색으로 합쳐짐),
  자재 발주(코인 1개로 시장 카드 3장 중 1장을 손패로, 한 턴에 한 번)

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `data/` | 숫자와 문구. 카드·문제·현장·다짐·현장 말·단원 분류. **코드를 몰라도 여기만 고치면 됩니다** |
| `js/` | 규칙 엔진(`engine.js`)과 화면들 |
| `css/`, `fonts/` | 스타일, 갈무리 글꼴 (SIL 오픈 폰트 라이선스, `fonts/LICENSE.txt`) |
| `tools/` | 점검 도구 |

## 점검 도구 (Node.js 필요)

```
node tools\rulecheck.js     규칙이 PRD대로 동작하는지 하나씩 점검
node tools\simulate.js      자동 대전 (현장·난이도·데일리·수업 현장별 준공률과 판 길이)
```

## 배포

정적 파일뿐이라 폴더 그대로 GitHub Pages나 Vercel에 올리면 됩니다.
GitHub Pages: 저장소에 올린 뒤 Settings → Pages → 브랜치 `main`, 폴더 `/ (root)`.

## 남은 확인 사항

- 카드 하단 설명·용어 풀이·문제 해설의 출처(`loreSource`)를 교재·표준시방서와 대조해 채우기
- 현장 말 목록을 건설 용어 순화 자료와 대조, 실무자 확인
- 플레이테스트로 능력치·벽돌·공기 수치 조정
- 게임 제목 확정
